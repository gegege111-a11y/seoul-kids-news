# 서울 키즈 클래스 뉴스 🎒

서울시 **공공서비스예약** `문화체험` + `교육강좌` 중 초등학교 **4~6학년** 관련 소식을 모아 매일 업데이트하는 모바일 웹앱입니다.

- iPhone Safari, 갤럭시 Chrome에서 같은 뉴스 URL 사용
- 서울시 공식 Open API `tvYeyakCOllect`에서 하루 1회 데이터 수집
- 뉴스/전체 탐색/관심 저장, 지역·분야·무료·주말 필터
- 새로운 수집 프로그램 NEW, 접수 시작 예정, 마감 임박 배지
- 서울시 원문 예약 상세페이지 연결
- 관심 목록은 **각 기기의 브라우저 안에만 저장**되며 서로 동기화되지 않음
- 예약 잔여석 및 상세 신청 자격은 실시간이 아니므로 원문 확인 필수

## 1. 먼저 로컬에서 미리보기

`index.html`을 웹브라우저로 열면 공식 서울시 페이지에서 확인한 **공식 개별 페이지에서 확인한 공고 6건**이 나타납니다. `data/events.json`은 정기 자동 수집 데이터가 아닌 2026년 10월 9일 수동 확인 스냅샷입니다. 실제 자동 갱신은 아래 설정을 완료해야 작동합니다.

개발 중 서버 미리보기:

```sh
python3 -m http.server 8080
# http://localhost:8080
```

## 2. 서울시 Open API 인증키 발급

1. [서울 열린데이터광장](https://data.seoul.go.kr/) 회원 로그인
2. `Open API` → `인증키 신청`에서 **일반 인증키** 발급
3. 사용할 데이터셋: [서울시 공공서비스예약(종합) 정보](https://data.seoul.go.kr/dataList/OA-20497/S/1/datasetView.do)
4. API 서비스 이름은 **`tvYeyakCOllect`**입니다.

**API 키를 ChatGPT 채팅, index.html, JavaScript, 공개 저장소에 붙여 넣지 마세요.** 서울시 이용약관상 인증키는 타인에게 제공·공유할 수 없습니다. 자신이 관리하는 배포 플랫폼 비밀값에만 등록하세요.

## 3. 추천: Vercel 무료 웹앱으로 배포하기 — 접속 시 새 데이터 조회 가능

**사용자가 원하는 “아침 수집 결과가 없으면 앱 첫 접속 때 실제 한 번 재조회” 기능은 정적 HTML만으로 불가능합니다.** 제공된 `api/events.py`는 안전하게 서버에만 저장된 인증키를 사용하여 최신 자료를 요청합니다.

1. 이 ZIP을 풀어 GitHub 저장소에 업로드합니다 (API 키는 넣지 마세요).
2. [Vercel](https://vercel.com/)에 가입하고 GitHub 저장소를 Import합니다. Framework는 `Other`를 선택합니다.
3. Vercel 프로젝트 → Settings → **Environment Variables** → `SEOUL_API_KEY` 등록. 값은 본인 계정에서 발급한 서울시 키.
4. Deploy하면 `https://...vercel.app` 주소가 발급됩니다. 아내에게 카카오톡으로 공유하세요.
5. 브라우저가 해당 페이지를 열 때 오늘 수집 성공본이 없다면 `/api/events?slot=early|morning`에 요청합니다. 오전 9시 15분 전후의 캐시를 분리해, 일찍 열었더라도 9시 15분 이후 새 수집을 시도할 수 있게 했습니다. 서버가 서울시 API를 호출하고 응답은 Vercel CDN에 오전 전후 각각 최대 10시간 캐시합니다. API 장애 시 이전에 수동 확인한 카드와 갱신 실패 안내를 유지합니다.
6. `vercel.json`에는 매일 오전 9시 15분(KST) 실행 목표인 Vercel Cron도 설정했습니다. **Vercel 무료 플랜은 실행 시각 오차가 최대 약 1시간일 수 있습니다.** 빈 데이터의 최초 방문에서도 재시도합니다.

⚠️ **아직 실제 API 키가 연결되지 않아 서버 기능의 서울시 실데이터 응답은 검증하지 못했습니다.** 최초 배포 후 갱신 시각과 카드 수가 실제 늘어나는지 확인해야 합니다.

## 4. 대안: GitHub Pages로 배포하기 — 매일 갱신만 (접속 즉시 갱신 불가)


1. GitHub 새 **Public Repository** 생성 (예: `seoul-kids-news`). 기본 브랜치는 **main**.
2. 이 ZIP의 압축을 풀고 모든 파일/폴더를 저장소 루트에 업로드합니다. `.github/workflows/daily.yml`까지 경로가 유지되어야 합니다.
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 클릭:
   - **Name**: `SEOUL_API_KEY`
   - **Secret**: 2단계에서 받은 API 키
4. **Settings → Pages → Build and deployment → Source: GitHub Actions** 선택
5. **Actions → Seoul Kids News - daily update & publish → Run workflow** 한 번 실행
6. 성공하면 **Settings → Pages**에 공개 주소가 나타납니다. 보통 `https://사용자명.github.io/seoul-kids-news/` 형태입니다.

이제 매일 한국 시간 **오전 9시 15분 전후** (GitHub 일정 지연 가능)에 데이터를 업데이트해서 사이트를 다시 게시합니다.

> GitHub Actions 무료 한도·정책에 따라 실행이 제한될 수 있습니다. 특히 Public Repo라도 활동이 오랫동안 없으면 일정 실행이 중지될 수 있으니 Actions 화면에서 상태를 확인하세요. API 수집에 오류가 나면 기존에 게시한 데이터가 유지되고 실패 로그가 남습니다.

## 5. 아내와 공유, 홈 화면에 추가

- **아이폰**: Safari에서 공개 URL 열기 → 공유 → **홈 화면에 추가**
- **갤럭시**: Chrome에서 공개 URL 열기 → 메뉴(⋮) → **홈 화면에 추가** 또는 설치
- 앱의 **공유** 버튼으로 URL을 카카오톡에 보내면 됩니다.

웹앱 콘텐츠는 두 기기에서 동일하게 보이지만 개인별 관심 저장 목록은 **각각 따로** 관리됩니다. 두 사람이 저장 목록도 실시간 동기화하려면 로그인과 별도의 데이터베이스가 추가로 필요합니다.

## 데이터 처리 규칙

- 기준: 초등 4~6학년 **명시** → `고학년 대상 명시`; 초등·어린이 대상만 적힌 경우 → `대상 학년 원문 확인`
- 저학년(1~3학년)만 명시한 모집과 성인용 강좌를 제외합니다.
- 접수기간이 끝난 프로그램과 예약마감·이용종료를 제외합니다.
- API의 분류/서비스명/대상 텍스트를 바탕으로 자동 분류하므로 누락·오분류 가능성이 있습니다.
- `주말 포함` 필터는 행사 운영기간에 토요일·일요일이 포함된 후보를 찾습니다. **실제 토·일 회차 개설을 보증하지 않습니다.**
- 모집 상태와 실시간 잔여석은 다른 정보입니다. `접수 중`이라고 해도 인원이 가득 찼을 수 있습니다.
- NEW는 **지난번 수집 때 없고 이번 수집에서 처음 발견된 프로그램**을 뜻하며, 정확한 공고 게시 시각과는 다를 수 있습니다.
- 데이터 출처: 서울특별시 서울열린데이터광장 (`공공누리 1유형`, 출처표시). 본 웹앱은 서울시 공식 운영 서비스가 아닙니다.

## 기술 구성

HTML/CSS/JavaScript + Python 표준 라이브러리 API 수집기 + Vercel Serverless Functions/Cron(접속 시 갱신) 또는 GitHub Actions+Pages(정적 매일 갱신). 개인적인 무료 제공 한도 내에서 운영할 수 있지만, 가입·설정이 필요하고 제공업체 정책에 따라 한도가 달라질 수 있습니다.
